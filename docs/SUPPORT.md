# Support

Use GitHub Issues for reproducible defects and specific migration cases. Include a minimal redacted template, the codemod version, Node.js and Angular versions, the selected target, and the relevant diagnostic.

Use a feature request for a recognized directive or target behavior that is not yet supported. Questions about general Angular, CSS, or Tailwind usage are outside this project’s support scope.

Report vulnerabilities through GitHub private vulnerability reporting as described in [SECURITY.md](../SECURITY.md). Never post credentials or confidential application source in a public issue.
