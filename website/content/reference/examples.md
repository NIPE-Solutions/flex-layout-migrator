# Verified examples

## Examples are executable claims

Each published transformation example must match the current production preview boundary for its input and target. Expected HTML, CSS, status, and diagnostic codes belong to the verified example registry rather than untested prose.

Examples demonstrate one bounded source case. They do not extend compatibility to dynamic values, surrounding application selectors, or directive combinations that are absent from the fixture.

## Read preserved output too

A useful reference includes cases where source remains unchanged. Preservation examples show the boundary where human intent or unsupported semantics matter and link the result to an actionable diagnostic.

Use the browser playground to vary one input locally, then use a CLI plan for project discovery, reports, stylesheet coordination, and writes.
