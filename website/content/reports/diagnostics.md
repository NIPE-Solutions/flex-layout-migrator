# Diagnostics

## Why wasn't this migrated?

A diagnostic explains why the engine did not prove an automatic replacement or why the result needs review. The code is stable enough to link from reports and documentation, while the message and suggestion supply source-specific context.

Read the diagnostic together with its file, location, directive family, target, and neighboring output. A code alone cannot reveal application runtime intent.

## Resolve the cause

Typical resolution paths include repairing invalid source, removing a destination conflict, confirming a project-specific option, selecting another target, simplifying a dynamic binding, or completing a manual migration.

Rerun the same scope after the change. The public diagnostic registry supplies the exact current code set and remediation detail without requiring prose pages to maintain a second list.
