# Allowing unresolved work

## Policy is not conversion

Allowing unresolved work changes how an otherwise completed run participates in process policy. It does not convert preserved source, remove diagnostics, expand target compatibility, or certify the remaining directives as safe.

Use this behavior when another review system intentionally tracks the unresolved set and a strict process status would duplicate that policy.

## Record the accepted boundary

Capture the report, exact command, scope, target, and rationale for every accepted unresolved category. Separate temporary migration debt from source that is intentionally staying on Flex-Layout.

Revisit the decision when source changes, target support changes, or the package version changes. A previous acceptance is not evidence that a new diagnostic or different template is equivalent.
